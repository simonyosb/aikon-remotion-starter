# ลาเต้เย็น 45 บาท: คลิปโปรโมทที่ AI ทำให้ทั้งหมด

ไฟล์โปรเจกต์จากคลิป **สอนทำวิดีโอด้วย AI (Claude Code + Remotion)** ของช่อง AIKoNTH

คลิปแนวตั้ง 1080×1920 ยาว 15 วินาที ทุกบรรทัดในโฟลเดอร์ `src` Claude Code เขียนจากคำสั่งภาษาไทยด้านล่าง ไม่ได้แก้ด้วยมือเลย

## ต้องมีอะไรบ้าง

- **Claude แบบเสียเงิน** (Pro ขึ้นไป) เพื่อใช้ Claude Code
- **Node.js** เวอร์ชัน 20.19 ขึ้นไป โหลดฟรีที่ [nodejs.org](https://nodejs.org)
- **Remotion** ใช้ฟรีถ้าทำคนเดียวหรือบริษัทเล็ก ดูเงื่อนไขที่ [remotion.dev/license](https://www.remotion.dev/license)

## ทางที่ 1: ทำตามคลิปตั้งแต่ศูนย์

1. สร้างโฟลเดอร์ว่าง เปิด Terminal ในโฟลเดอร์นั้น แล้วพิมพ์

   ```bash
   npx create-video@latest
   ```

   กด Enter 3 ครั้ง (ยืนยันการติดตั้ง, เลือก Blank, ติดตั้งสกิลทั้งหมด) จะได้ทั้งโปรเจกต์และสกิลที่สอน Claude ทำวิดีโอ

2. เปิดหน้าพรีวิว

   ```bash
   npm run dev
   ```

3. เปิด Terminal อีกแท็บในโฟลเดอร์เดียวกัน พิมพ์ `claude` แล้วส่งคำสั่งนี้

   ```text
   ทำคลิปแนวตั้ง 9:16 ยาว 15 วินาที โปรโมทลาเต้เย็น 45 บาท ร้านมุมกาแฟ โทนครีม ฟอนต์ไทย Kanit ข้อความเด้งเข้าทีละบรรทัด
   ```

   ตอนซ้อม Claude ใช้เวลาราว 15 นาที ระหว่างนี้ปล่อยให้มันทำไปได้เลย

4. สั่งแก้ทีละอย่าง แต่ละครั้งใช้เวลาไม่ถึง 20 วินาที

   ```text
   ขยายคำว่า ลาเต้เย็น ให้ใหญ่ขึ้นอีก
   ```

   ```text
   เปลี่ยนพื้นหลังเป็นสีเขียวมัทฉะ
   ```

   ```text
   ลบอีโมจิออก และเปลี่ยนสีบรรทัด สดชื่นทุกแก้ว เป็นสีขาว
   ```

5. ใส่เพลง วางไฟล์เพลงชื่อ `music.mp3` ไว้ในโฟลเดอร์ `public` แล้วสั่ง

   ```text
   ใส่เพลง music.mp3 ในโฟลเดอร์ public เบา ๆ ตลอดคลิป
   ```

   ถ้า Claude ขออนุญาตติดตั้ง `@remotion/media` ให้กดอนุญาต

6. เรนเดอร์เป็นไฟล์ MP4

   ```bash
   npx remotion render LatteYen out/latte.mp4
   ```

   ได้ไฟล์ `out/latte.mp4` พร้อมโพสต์

ผลของ AI แต่ละครั้งไม่เหมือนกันเป๊ะ ชื่อคอมโพสิชันอาจไม่ใช่ `LatteYen` ดูชื่อจริงได้ในหน้าพรีวิว

## ทางที่ 2: เอาไฟล์ในนี้ไปแก้ต่อ

```bash
git clone https://github.com/simonyosb/aikon-remotion-starter.git
cd aikon-remotion-starter
npm i
npx -y skills@1.7.0 add remotion-dev/skills --skill '*' -a claude-code -y
npm run dev
```

แล้วเปิด `claude` ในโฟลเดอร์นี้ สั่งแก้เป็นภาษาไทยได้เลย เช่น

```text
เปลี่ยนเป็นชาไทยเย็น 40 บาท ใช้สีส้มชาไทย
```

## แถม: อีก 5 เมนู

ในคลิปมีกำแพงผลงาน 6 เมนู อีก 5 เมนูอยู่ใน `src/DrinkAd.tsx` Claude ทำจากคำสั่งเดียวนี้ ใช้เวลาไม่ถึง 2 นาที

```text
ทำคลิปแบบเดียวกับลาเต้เย็นเพิ่มอีก 5 เมนู
ชาไทยเย็น 40 บาท, มัทฉะลาเต้ 55 บาท, อัญชันมะนาว 35 บาท, นมสตรอว์เบอร์รี 45 บาท, โกโก้เย็น 45 บาท
ใช้สีพื้น สีเครื่องดื่ม และสีป้ายราคาให้เข้ากับแต่ละเมนู ไม่ใส่อีโมจิ
```

เรนเดอร์ทีละเมนูด้วยชื่อคอมโพสิชัน เช่น

```bash
npx remotion render ThaiTea out/thai-tea.mp4
```

ชื่อทั้งหมด: `LatteYen`, `ThaiTea`, `MatchaLatte`, `ButterflyPeaLime`, `StrawberryMilk`, `IcedCocoa`

## ถ้าเรนเดอร์ไม่ผ่าน

บน Mac บางเครื่อง เบราว์เซอร์ที่ Remotion โหลดมาใช้เรนเดอร์จะพังแล้วขึ้นข้อความ `Target closed` ถ้ามี Google Chrome อยู่ในเครื่อง ให้เรนเดอร์ด้วย Chrome ตัวนั้นแทน

```bash
npx remotion render LatteYen out/latte.mp4 --browser-executable "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"
```

ถ้ายังไม่ผ่าน ก๊อปข้อความ error ทั้งหมดส่งให้ Claude แล้วบอกว่า "เรนเดอร์ไม่ผ่าน ช่วยแก้หน่อย"

## เพลงประกอบ

`public/music.mp3` เป็นเพลงที่ทำด้วย AI สำหรับคลิปนี้ ถ้าจะใช้โปรโมทร้านจริง แนะนำให้เปลี่ยนเป็นเพลงที่ใช้ได้ฟรี เช่นจาก [คลังเพลงของ YouTube](https://studio.youtube.com/channel/UC/music)
